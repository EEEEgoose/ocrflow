# OCRFlow

<img src="icon96.png" width="64" alt="OCRFlow 图标" />

**简体中文** · [English](README.en.md)

面向 **Zotero 10**的AI文档识别工作流插件。支持多个OCR工具，支持条目整理、识别勘校，文献总结翻译等功能。

本插件基于个人需求开发，感谢MinerU for Zotero、Paper Outline等Zotero插件提供的思路，为了避免多次配置相关服务，将其功能整合在内方便使用。

[下载安装](https://github.com/EEEEgoose/ocrflow/releases/latest) · [使用手册](README.zh-CN.md) · [页进度接口部署教程](docs/OCR-PROGRESS-DEPLOYMENT.zh-CN.md) · [更新记录](CHANGELOG.md)

## 可以做什么

| 操作 | 结果 |
| --- | --- |
| 一键整理 | 识别文档 → 建立条目 → 补全条目 → 翻译标题 → 总结文献 → 翻译文献 → 生成大纲 |
| 识别文档 | PDF / 图片 OCR 或文档转 Markdown，按需同时生成 HTML |
| 建立条目 | 仅根据文件名创建初步书目条目 |
| 补全条目 | 从全文提取书目信息，非中文题名的中文译名写入短标题 |
| 总结文献 | 生成学术总结，保存为文献下的笔记 |
| 翻译文献 | 按自然段翻译；双栏 HTML 每段对应，跨页未完正文先接回同一段 |
| 翻译标题 | 直接翻译父条目原标题，写入短标题；支持 AI、DeepL 与 DeepLX，无需全文 |
| 生成大纲 | 为关联 PDF 生成可导航的阅读器大纲 |

一键整理复用已有全文与父条目，补全缺失信息；非 PDF 跳过大纲。大纲或总结失败后继续后续工作，重试只补跑未完成步骤。各功能也可单独执行。

## 识别与校勘

- 支持 **MinerU 本地 / 云端、PaddleOCR 官方 / 自部署、Marker（自部署 / Datalab 在线）、MarkItDown、AI 视觉 OCR**。Marker 当前接收 PDF；EPUB、Office 等由 MarkItDown 转换。
- 保留原始响应、正文结构、脚注图注、物理页来源及已有坐标；跨页合并保留来源片段，并生成整理差异报告。
- 可选双引擎独立识别，A 生成底稿、B 提供对照；相同引擎不能重复选择。可选 AI 结合原图校勘，明确建议自动另存新版本，底稿、依据与差异保留；不确定项保持原文。
- 最多保存 5 个 AI 服务商，每家两个模型；各项工作独立选择模型、提示词和请求参数，模型独立配置上下文、输出长度和并发。
- 侧栏展示执行步骤与真实进度，完整任务列表在设置中。支持终止、重试、翻译补段及查看结果；Marker 短暂断网后重连原任务，不重复上传。
- 配置统一加密保存，支持加密导入 / 导出，以及通过 Zotero 文件同步传输密文配置包；详见[同步功能](docs/CONFIGURATION-SYNC.zh-CN.md)。
- 不同文献的不同操作、服务和模型可并行调度；AI 请求共享模型并发上限，同一文献的冲突操作继续等待。服务端自身的排队限制仍然生效。

## 界面语言

同一安装包支持中文和英文界面，自动跟随 Zotero：中文环境使用中文，其他语言环境使用英文。更改 Zotero 界面语言后重启生效。界面语言不会更改文献内容、已保存的 Prompt 或总结 / 翻译目标语言。

## 安装与开始使用

1. 从 [最新 Release](https://github.com/EEEEgoose/ocrflow/releases/latest) 下载 `.xpi`。
2. Zotero → 工具 → 插件 → 从文件安装插件。首次安装后完整重启 Zotero。
3. 设置 → OCRFlow → 同步功能，先创建配置密码或导入加密配置，再配置识别服务及 AI 模型。
4. 选中一个文件或文献，在右侧 OCRFlow 面板执行操作；多份原文件时先选本次处理的附件。

已有任务运行时，先等待任务结束再更新插件，以保留当前会话的队列与任务 ID。当前任务队列和未完成译段缓存不会跨 Zotero 重启保留；服务端任务及已保存附件与客户端会话不同步清除。

旧 DocFlow / OCRFlow 可覆盖安装。仍使用其他自动识别插件时，请检查其自动处理设置，避免同一文档重复提交。Zotero 通过最新 Release 的 `updates.json` 检查更新；使用旧占位更新地址的版本需先手动覆盖安装一次。

## 数据与许可

执行操作时，文件名、全文、原文件或页面图片按功能发送给用户选择的服务；仅查看和选中文献不触发任务。API Key 等配置保存在本地加密仓库中，不随源码分发。
