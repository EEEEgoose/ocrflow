OCRFlow 1.2.3

本次正式发布包含结构化 OCR 与侧栏改版，开发记录覆盖 1.0 至 1.2.9。

## 新增功能

- 新增 PaddleOCR 官方异步 API 与自部署文档解析 API，两套连接配置独立保存。
- 保留原始 OCR 数据、文档结构、脚注图注、跨页来源和整理差异报告；译文双栏按自然段 ID 对齐。
- 可选双引擎独立识别与原图校勘；可选 AI 结合原图给出建议，本版本仍需人工确认后另存新版本。
- Zotero 主界面右侧新增 OCRFlow 图标、当前文献操作与任务执行步骤；完整队列移入设置页。
- 设置改为顶部分类标签；工作独立选择模型和提示词，PaddleOCR 合并默认入口，MinerU 请求超时默认 1200 秒。
- 右键菜单按工作类别分组，采用 SVG 图标；支持终止、重试、查看结果及校勘 / 差异入口。

## 修复问题

- 修复关闭设置后出现 can't access dead object、任务停在排队，以及菜单本地化缺失导致的空白项。
- 修复侧栏按钮被原生样式裁切、点击被刷新打断，以及任务和附件下拉框无法选择。
- 修复笔记、普通 Markdown、OCR HTML 与原文件的识别和操作条件，明确提示缺少父条目、全文或 PDF。
- 修复图片引用路径不匹配导致保存失败，保留原始引用并避免重复插入图片。
- 修复原图校勘窗口透明、内容混叠、长内容撑高布局；原图加载可重试，保留人工草稿。
- 修复设置重开后校勘来源和 AI 模型未恢复，原图复用已打开阅读器，同页分歧复用图片。
