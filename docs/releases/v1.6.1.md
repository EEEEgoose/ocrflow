# OCRFlow v1.6.1

## 超长文件名修复

- 修复超长书名在生成 HTML、Markdown 或重命名附件时触发 `NS_ERROR_FILE_NAME_TOO_LONG` 的问题。
- 保存和重命名共用文件名生成逻辑，按 UTF-8 字节将文件名（含扩展名）限制在 255 字节以内，按完整 Unicode 字符截断。
- 为扩展名预留空间，保留识别、翻译及 HTML 布局前缀。Zotero 附件显示完整标题，HTML 的配套 Markdown 使用对应文件名。

## 验证

420 项插件测试通过。新增回归测试覆盖超长英文、法文、中文、阿拉伯文和表情字符书名，以及 HTML / Markdown 保存、附件重命名和配套 Markdown 移动。
