OCRFlow 1.2.4

此正式发布对应当时开发记录 1.2.10，以下按 v1.2.3 到本标签的实际改动整理。

## 新增功能

- 本次以翻译恢复与限流修复为主，未新增独立功能。

## 修复问题

- 修复失败重试未使用最新模型配置的问题；重试读取刚保存的服务、模型与请求参数，保留已完成译段。
- 显示具体 API 或格式错误；等待处理失败译段时明确暂停，不再持续显示执行中。
- 没有完整译段时禁止保存部分译文；更改目标语言时提示重新开始，避免混合语言。
- HTTP 429 遵守 Retry-After，缺少该字段时递增等待；重试耗尽后暂停后续批次，等待期间可终止。
- 翻译批次同时受模型输出预算约束，减少超出输出额度导致的漏段。
- 补充插图处理、模型请求与限流等待状态，避免进入模型请求后仍停留在“读取自然段与来源”。

## 安装与文档

下载本页 `.xpi` 安装到 Zotero 10。此版本尚不包含后续新增的 Marker 任务接口和 AI 自动采用校勘功能。
