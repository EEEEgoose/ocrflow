OCRFlow 1.3.4

相较正式版本 1.2.4，本次包含此前未单独发布的跨页翻译、Marker 接入及完整整理流程。

## 新增功能

- 新增 Marker 自部署 PDF OCR：整份文件上传一次，查询任务与真实页响应进度，完成后下载完整 Markdown、图片和来源资料。
- 提供 Marker 2.0.0 / Surya 2 的持久化任务、结果和取消接口；Marker 可作为双引擎来源。
- 一键整理扩展为识别文档、建立条目、补全条目、生成大纲、总结文献、翻译文献六步；复用已有结果，失败重试只补跑未完成步骤。
- AI 辅助校勘可直接采用明确建议并另存新版本；保留底稿、原始识别、模型依据与差异，不确定项保留原文。
- 设置按钮增加按压动画、异步忙碌及保存成功 / 错误反馈；侧栏可直接查看总结和译文。

## 修复问题

- 翻译前接回跨页未完正文，避免同一自然段因物理分页分开翻译；双栏保留全部来源页码。
- 修复 Marker 同步连接断开后遗留后台任务的问题；取消针对具体任务，保留共享推理服务。
- Marker 提交未返回任务 ID 时明确标记取消未确认，避免误报服务端已停止。
- 修复 Marker 排队时误显示正在识别及 0/N 页进度；区分服务端排队、实际识别和结构整理。
- 修复“任务信息”被侧栏刷新收起；Marker 查询和下载短暂断网时自动重连原任务，持续中断后可继续等待，无需重传。
- 统一“识别文档”“补全条目”“生成大纲”等名称，保留 AI 校勘后的人工修正路径。

## 安装与文档

- 下载本页 `.xpi`，在 Zotero 的“工具 → 插件 → 从文件安装插件”中安装。建议等当前任务完成再更新，以保留当前会话的队列。
- Marker 页进度与取消需要同步升级服务端任务接口，仅安装插件不会更新服务器。
