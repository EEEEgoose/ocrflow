# 加密配置管理与同步

[项目首页](../README.md) · [使用手册](../README.zh-CN.md)

适用于 OCRFlow 1.5.0（加密配置功能始于 1.4.0）。配置管理位于设置的“同步功能”标签，文献正文、识别结果和任务进度不属于配置包。

## 首次使用与解锁

1. 更新前先等当前任务完成，再安装插件。
2. 打开 Zotero 设置 → OCRFlow → 同步功能。
3. 输入至少 10 个字符的配置密码，并再次确认，点击“创建配置密码”。现有服务地址、API Key、服务商、模型、提示词和输出设置会转入加密仓库；迁移成功后清除原明文插件配置。
4. 解锁后正常配置服务和执行任务。未创建密码或未解锁时，不能读取配置启动新任务。

本地文件为 Zotero 数据目录下的 `ocrflow-config.enc`。使用 Web Crypto 的 AES-256-GCM 加密，PBKDF2-SHA256（600,000 次）派生密钥，每次保存生成随机盐与 nonce。运行时需要解密到内存；磁盘配置、导出文件和同步附件均为密文。

可勾选“使用本机安全凭据存储记住解锁”，由 Zotero 运行环境的凭据管理服务保存解锁信息，不写回插件首选项，也不参与配置同步。没有相应凭据服务的环境会禁用此选项。未记住时，每次启动后需要解锁。

“锁定配置”清除设置页中的敏感输入与缓存。运行中的任务需先结束，避免中途锁定影响任务。

## 导出、导入与密码

- **导出加密配置**：选择保存位置，生成 `.ocrflow-config` 文件；包含已保存的完整配置，使用当前配置密码。
- **导入加密配置**：输入该文件的密码并选择文件。预览只显示设置数量和服务商数量，不展示 API Key；确认后整套替换，保留服务商与模型引用关系。
- 已有本机配置在替换前保留为加密备份 `ocrflow-config.enc.backup`。错误密码、损坏文件或无效引用不会修改当前配置。
- 普通文件导入保留本机原有解锁密码；在尚未创建本机配置的新设备上导入时，使用导入密码作为本机密码。
- **修改配置密码**：输入新密码并确认；只影响后续本地保存与新同步包。旧导出和旧备份仍需要原密码。

密码不包含在配置包中。遗失密码后无法恢复已经加密的配置，需重新配置服务。

导入或同步应用不改变运行任务的配置快照；新任务和明确重试读取新配置。页面中的未保存编辑请先保存，再导出或同步。

## 通过 Zotero 官方同步传输

1. 在 Zotero 自身设置中登录同一账号并启用个人文库的文件同步，可使用 Zotero Storage 或现有 WebDAV。
2. 解锁配置，勾选“通过 Zotero 文件同步传输加密配置”，点击“保存同步选择 / 生成同步包”。
3. 插件在个人文库的“OCRFlow 配置同步”条目下创建密文附件。随后由 Zotero 自动同步；未开启自动同步时，点击 Zotero 原生同步按钮。
4. 其他设备安装 OCRFlow，先完成 Zotero 同步，在“同步功能”输入共享配置密码，点击“检查远端配置”。按需下载尚未在本地的附件。
5. 选择版本，点击“预览并应用所选配置”。新设备可直接恢复；已有加密仓库的设备须先解锁本机配置。

本机生成同步附件不表示服务器上传已经完成，云端传输状态以 Zotero 原生同步状态为准。仅启用数据同步、不启用文件同步时，另一设备可能看得到条目但拿不到配置包。

本功能不往 Zotero 的内部 SyncedSettings 写自定义键，也不收集 Zotero 账号密码，不需要独立 OCRFlow 云端账号。同步附件会占用相应文件存储空间。

## 多端修改与密码变更

每次配置快照记录父版本，密文附件保留版本历史。两台设备分别修改时，“检查远端配置”会保留多个分支供选择，不按设备时间自动覆盖，也不自动应用远端内容。

选择某个版本应用后，新的合并版本标记已处理的分支；其他设备再次同步后即可看到统一版本。更换共享密码后，其他设备先用旧密码解锁本机，再在远端检查时输入新密码；同步恢复会采用这次输入的密码作为新的本机解锁密码。

关闭配置同步会停止后续生成同步包，已经同步的密文版本继续保留。文献、OCR 结果和运行任务的跨设备同步不由此功能管理。
